## О проекте

Учебный проект интернет-магазина, реализованный на **React** с использованием **Redux** для управления состоянием. Серверная часть построена на **Node.js** и **Express.js** с базой данных **MongoDB**.

## Технологический стек

### Frontend

- **React** — библиотека для построения пользовательских интерфейсов
- **Redux Toolkit** — управление состоянием приложения
- **React Redux** — интеграция React с Redux
- **TypeScript** — типизация кода
- **SCSS Modules** — стилизация компонентов
- **Vite** — сборка проекта

### Backend

- **Node.js** — среда выполнения JavaScript на сервере
- **Express.js** — фреймворк для создания REST API
- **MongoDB** — NoSQL база данных
- **Mongoose** — ODM для работы с MongoDB
